# 任務管理系統 - 產品需求文件 (PRD)

## 1. 專案概述
- **背景與動機**：現代人生活與工作繁忙，需要一個簡單直覺的工具來記錄與追蹤待辦事項，以提升個人生產力與時間管理效率。
- **目標用戶**：需要管理日常工作的個人用戶。
- **核心價值主張**：提供輕量、易用的介面，讓使用者能快速新增、追蹤與管理待辦任務，不錯過任何重要事項。

## 2. 功能需求
以下為系統的主要功能，並以使用者故事（User Story）格式描述：

1. **新增任務**
   - 作為 **個人用戶**，我希望 **能夠快速新增一筆待辦任務**，以便 **記錄需要完成的工作**。
2. **標記任務完成**
   - 作為 **個人用戶**，我希望 **能夠將已做完的任務標記為完成**，以便 **清楚知道哪些事情已經處理完畢**。
3. **刪除任務**
   - 作為 **個人用戶**，我希望 **能夠刪除不再需要或輸入錯誤的任務**，以便 **保持任務清單的整潔**。
4. **顯示所有任務清單**
   - 作為 **個人用戶**，我希望 **能夠在一個畫面上看到所有待辦與已完成的任務**，以便 **總覽目前的工作量**。
5. **依完成狀態篩選**
   - 作為 **個人用戶**，我希望 **能夠依據「全部」、「未完成」、「已完成」來篩選任務**，以便 **專注於當前需要處理的事項**。

## 3. 非功能需求
- **技術限制**：系統採用 Python Flask 框架，搭配 Jinja2 模板引擎進行前端渲染，並使用 SQLite 作為輕量級關聯式資料庫。
- **效能與安全考量**：
  - 系統載入時間應在快速範圍內，提供良好的使用者體驗。
  - 實作基本的防護措施（例如避免 SQL Injection、XSS 攻擊）。
  - 確保使用者的任務資料安全且正確地儲存於資料庫中。

## 4. MVP 範圍 (Minimum Viable Product)
- **Must Have (必須具備)**：
  - 新增任務
  - 顯示所有任務清單
  - 標記任務完成
- **Should Have (應該具備)**：
  - 刪除任務
  - 依完成狀態篩選任務
- **Nice to Have (加分項目)**：
  - 任務分類標籤
  - 到期日與提醒通知
  - 響應式介面設計 (RWD)
